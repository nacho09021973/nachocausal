# Material histórico

Esta carpeta conserva documentos auxiliares o planes sustituidos que siguen
siendo útiles para trazabilidad, pero no forman parte de la ruta activa del
proyecto.

No usar estos archivos como contratos, resultados vigentes, preregistros ni
fuentes de claims sin comprobar primero el estado canónico en `README.md`,
`CLAUDE.md`, `INSTRUCCIONES.md` y `docs/`.
