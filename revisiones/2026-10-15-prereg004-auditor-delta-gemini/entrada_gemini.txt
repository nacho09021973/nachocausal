## 4. Observable and estimator

- **Observable:** for each minimal element i of the order, `O(i) = |future(i)|` (future

  minimal elements.

  `covers` iff `r_lo ≤ 2M ≤ r_hi`; `clean` iff width ≥ 0; point estimate = midpoint.

  classes of the split are non-empty (`scoring.scorer.blind_bracket`, `validate.per_seed`).

## 7. Frozen analysis

Grid `RHO_GRID = (32, 63, 126)`, **primary endpoint ρ\* = 126** (comité 052 §8 item 4). Every
threshold is a function of (ρ, T, box geometry) only, never of realised N or n_min.

**θ anchor (c1), derived blind** (`revisiones/2026-10-13-anclaje-theta-ciego/astra.md`, commit
`bab6fef`): radial order-statistic spacing of the minimal-element layer, evaluated at the mean box
perimeter `P* = π(R_LO + R_HI) = 1.4π` (box ends only, no ground truth); K_LOC = 2 inherited
unchanged.

```text
ell_rad(ρ)    = ρ^(-2/3) / (1.4π)
theta_loc(ρ)  = K_LOC·ell_rad/(2M)
theta_stab(ρ) = K_LOC·ell_rad
slack(ρ)      = ell_rad/(2M)            (convergence clause F)

ρ       theta_loc   theta_stab
32      0.09023     0.04511
63      0.05744     0.02872
126     0.03619     0.01809
```

**Disclosure (required by comité 052 §6):** the anchor was commissioned when the chair already
knew the dev bracket widths; the deriver (ASTRA) did not see them. The conservative alternative
(c2), the dimensional transfer `2ρ^{-1/3}/2M` with an explicit "(ii) and (iii) are weak in 2+1"
note, was recorded and not chosen (PI decision, comité 052 §11). These θ have **not** been
compared with dev widths and will not be before the freeze. A low-ρ cell failing under this anchor
is reported as a FAIL, not repaired.

**Criteria** (`nachocausal2p1/validate.py` `summarise_level`, `verdict_from_levels`). The run is
**PASS iff (i)-(iv) hold**, with (v) as a precondition (below); otherwise FAIL, except for the
statuses listed under "Verdict precedence".

| Check | Definition |
|---|---|
| (i) significance | at every ρ ≥ 63: sign-flip `p_perm ≤ 1e-4` on `d = sep_BH − sep_MINK` over generator-valid seeds (exact for n ≤ 20; a BH abstention enters with sep = 0), **and** BH abstentions < 3 at that level |
| (ii) localisation | at ρ\*: median clean width/2M ≤ θ_loc(ρ\*), **and** IQR of clean widths/2M ≤ θ_loc (a larger or NaN IQR fails (ii); the code field `loc_inconclusive` means this FAIL, not the run verdict INCONCLUSIVE), **and** coverage ≥ 0.5 over bracket-valid seeds |
| (ii) convergence F | for consecutive grid levels: `m(ρ_{k+1}) ≤ m(ρ_k) + slack(ρ_k)`, m = median clean width/2M; a NaN median (no clean bracket at a level) fails it |
| (iii) stability | at ρ\*: population std (ddof = 0) of clean bracket midpoints ≤ θ_stab(ρ\*) |
| (iv) flat escapes | at ρ\*: flat-control non-abstentions ≤ 1 of the generator-valid seeds |
| (v) order-only | precondition, not a criterion that can be false in the validation run: the validation label refuses `guard=False` and a Guard-v failure raises (`ABORTED_GUARD_V`, §9). It is not counted as a passed criterion |

- **Verdict precedence** (as coded, `validate.py` `run` and `verdict_from_levels`):
  `OUT_OF_DOMAIN` > `ABORTED_GUARD_V` / `ABORTED_TAU_RANGE` (§9) > `INCONCLUSIVE` > `PASS`/`FAIL`.
  - **OUT_OF_DOMAIN** iff `T < T_EDGE_MIN = 10`. At the frozen T = 16 this gate cannot fire and
    is **not** counted as a safeguard (comité 052 §5 "Verdict coercion").
  - **INCONCLUSIVE** iff **any** level of the grid has < 18 generator-valid seeds (PI decision of
    2026-10-14 after the O8 review, D2; before, only the primary level counted and a short
    secondary level gave FAIL). It is evaluated **before** (i)-(iv), and the verdict then carries
    no per-clause `checks`; so it takes precedence over any FAIL, including a FAIL of (i) at
    ρ = 126 when ρ = 32 is short (`tests/test_004_criteria_can_fail.py`
    `test_inconclusive_takes_precedence_over_a_fail_of_i`).
  - **BH abstentions never cause INCONCLUSIVE**: when every level has ≥ 18 generator-valid seeds,
    ≥ 3 BH abstentions at a required level is a **FAIL** of (i) (PI decision, comité 052 §11).
  - **Under INCONCLUSIVE**, the result document also reports, from the recorded level
    aggregates, the value each clause (i)-(iv) would have taken, labelled **non-verdict**, so that
    a failure masked by INCONCLUSIVE is visible. These values never turn INCONCLUSIVE into a PASS
    or a FAIL (comité 053 §8 item 1). The code does not produce them (`verdict_from_levels`
    returns before building `checks`); the result document computes them by hand from
    `levels[ρ]`, applying the inequalities of the table to the recorded aggregates. A clause
    whose input is a count over **zero** generator-valid seeds (for example `n_escape_MINK = 0`,
    `n_abstain_BH = 0`) is reported as **not evaluable**, not as passed.
- **NaN never passes** (O8 review, D1): every pass comparison is false on NaN (`≤` for (ii),
  F, (iii), (iv); `≥` for the coverage floor; `<` for the abstention count, which is an integer).
  A level with no clean bracket has NaN median, IQR and midpoint std. With exactly **one** clean
  bracket the median is defined, the IQR is NaN and the midpoint std is **0.0**, not NaN. **At
  ρ\*** (iii) then passes on its own, but (ii) fails through the IQR, so the run cannot PASS
  (`test_one_clean_bracket_passes_iii_but_fails_ii`). At ρ = 32 or 63 only the median enters
  (through F); the IQR and the midpoint std of those levels are reported but are not criteria, so
  a secondary level with one clean bracket can be part of a PASS.
- **(i) and (iv) are gate-derived.** With the flat control abstaining, `d ≥ 0` on every seed and
  the exact sign-flip test gives `p = 2^-m`, with m the number of seeds where the BH passes the
  gate, whatever the size of `sep_BH`. So (i) reduces to "fewer than 3 BH seeds abstained" at
  each required level, and (iv) to "≤ 1 flat seed escaped the gate". The reduction of (i) needs
  **no** flat escape at that level: (iv) allows one at ρ\* and does not limit escapes at ρ = 63,
  and an escape can make `d < 0` on a seed, so (i) can then also fail through `p_perm`. Neither is independent
  confirmation; the discriminating content is (ii), (iii) and coverage (comité 052 §8 item 7;
  O8 review, D10 and D12).
- **Declared dependence between levels** (O8 review, D7; inherited from 1+1,
  `nachocausal/generator.py:46`). The three ρ levels use the same 20 seeds, and each seed seeds
  `numpy.random.default_rng(seed)` with no ρ. The levels therefore share their random stream:
  the first `n(32)` values of `t` at ρ = 63 are the `t` of ρ = 32, and the next ones are the
  uniforms behind `r` at ρ = 32 (checked on seed 7_000_100). Each level is a correct Poisson
  sprinkle, but the levels are **not independent**, and the convergence clause F compares
  correlated medians. This is declared, not changed (PI decision, 2026-10-14), so that the dev
  parity records stay valid.
- **Declared selection on clean brackets** (O8 review, D8; as 1+1, `nachocausal/validate.py:136`).
  The median and IQR of widths and the midpoint std use only clean brackets (`width ≥ 0`);
  inverted brackets (`r_lo > r_hi`) are left out of them, and only coverage, over all
  bracket-valid seeds, sees them. `n_clean` is reported per level.
- **Reported verbatim and separately, whatever the verdict:** per level, generator-invalid count
  and reasons, BH-abstain count, flat-escape count, bracket-valid and clean counts, coverage count
  (not only the fraction), median and IQR width/2M, midpoint std, p_perm. These descriptive
  aggregates are also reported when a level has fewer than 18 generator-valid seeds;
  its status and the run verdict remain INCONCLUSIVE. Empty samples have zero counts and
  NaN statistics (IQR is also NaN with one clean bracket), never a statistical PASS.
- **Known weakness, stated in advance** (comité 052 §5 item 5; ASTRA risks): a narrow, reproducible
  but mislocated bracket can pass (ii)-width and (iii); only coverage catches it, and with floor
  0.5 up to 10 of 20 non-covering seeds still PASS. The coverage floor 0.5 is a deliberately weak
  floor, not nominal coverage, and is neither raised nor lowered.
- **Low power of (ii)-width and IQR, stated in advance** (comité 053 §8 item 7). This follows
  from theory only: the ASTRA neighbour model (`revisiones/2026-10-13-anclaje-theta-ciego/astra.md`
  l.33-46) and the frozen formula. No dev JSONL and no dev width was consulted to write it.
  For a classifier that splits the minimal elements exactly at r = 2M, the bracket is the gap
  between the nearest minimal elements on either side in radial projection. With radial
  intensity `λ_r(2M) = c₃ρ^{2/3}·2π(2M)√2`, `c₃ = Γ(4/3)(3/π)^{1/3} ≈ 0.879`, each side is
  Exp(δ) with `δ = 1/λ_r(2M) ≈ 0.256 ρ^{-2/3}`, and the width is Gamma(2, δ). The bound
  `θ_loc·2M = 2ρ^{-2/3}/(1.4π) ≈ 0.455 ρ^{-2/3} ≈ 1.78 δ`. Then P(one width ≤ bound) =
  `1 − e^{-1.78}·2.78 ≈ 0.53`; the median width is `1.678 δ ≈ 0.94` of the bound; the IQR is
  `1.73 δ ≈ 0.97` of the bound. So even an ideal order-only localiser passes the width and IQR
  clauses at ρ\* only about half the time `[UNVERIFIED — closed-form arithmetic in a flat-local
  approximation, ρ^{-1/3} ≈ 0.2 not ≪ 2M; no simulation]`. This is a property of the test, fixed
  before any validation data. **A FAIL is reported as FAIL**, with no qualifier added after the
  result. **No result of this run may be used to re-derive, rescale or loosen θ_loc, θ_stab or
  K_LOC**, here or in any successor pre-registration.

**Can-fail evidence (step 4):** `tests/test_004_criteria_can_fail.py` (20 tests) shows (ii) via
coverage, (ii) via width, (iv) and (v) can each produce FAIL; since the O8 review (D9) it also
shows, each failing alone, (i) by 3 BH abstentions at ρ = 63, the convergence clause F, (iii),
the IQR clause of (ii), a NaN median failing F, a NaN IQR never passing, and a short secondary
level giving INCONCLUSIVE; since comité 053 it also fixes the verdict precedence (a short level
gives INCONCLUSIVE with no `checks` even with 3 BH abstentions at ρ\*) and the one-clean-bracket
case. (v) is shown false only outside the validation label, where it is a precondition (§7).
`dev/mutation_check_004.py` catches
5/5 mutations (`dev/PREREG004_STEP_4_2026-10-13.md`).

## 9. Binding rules and sequence

- **One-way:** the single blind `python -m nachocausal2p1.validate` on the drawn seeds, with
  `guard=True`, is the only evaluation. It has not been run. It is launched once, as an explicit
  step, only after explicit PI authorisation.
- **Report alike:** PASS, FAIL, INCONCLUSIVE or OUT_OF_DOMAIN is recorded and reported regardless
  of which it is. No post-hoc tuning, no re-running on fresh seeds after a result, no loosening of
  a frozen threshold. An unmet principled threshold is informative, never a licence to retune
  (`docs/preregistration.md:55-57`).
- **Invalid seeds** (§3) count toward the < 18/20 INCONCLUSIVE rule and never trigger
  replacement seeds.
- **Crash rule:** a crash is relaunched on the **same** seeds, environment and commit, **only if
  no scoring output was produced**, and the relaunch is logged with timestamps. The progress log
  below records each launch (a `start` line with its time) and carries no scoring field.
- **Writing:** `results/validation_004.json` is written atomically. `results/` is git-ignored
  (`.gitignore:21`), which keeps the tree clean during the run (the seed guard re-checks
  `git status --porcelain`), so a plain `git add` records nothing. Immediately after the run
  ends, crashes or aborts, the four run files are **force-added** by name in one commit:
  `git add -f results/validation_004.json results/validation_004.progress.jsonl
  results/validation_004_provenance_launch.txt results/validation_004_run.log` (only the files
  that exist), with their `sha256sum` lines written into `docs/preregistration_004_result.md`
  in the same commit, and the commit is pushed (lesson of prereg-002 `PRIMARY_ARTIFACT_LOST`,
  `docs/preregistration_002_result.md`; comité 053 §8 item 4).
- **Run log:** the run's stdout and stderr go to `results/validation_004_run.log`, so the
  verdict line, or the traceback of an abort, is kept.
- **Progress log** (O4, §10): `results/validation_004.progress.jsonl`, one fsynced line per seed
  and level with only `seed, rho, seconds` (`validate.PROGRESS_FIELDS`), appended as the run
  goes. It says nothing about the outcome: abstentions and invalid seeds would reveal a FAIL of
  (i) or (iv) hours before the end (O8 review, D6). It is force-added with the result, or alone
  after a crash (Writing, above). Its `start` line uses local time with offset; the provenance
  file records UTC.
- **Deterministic aborts are not crashes** (O8 review, D11). A Guard-v failure or a seed with
  `n_minimal > 256` (outside the τ table) raises and stops the run without a result. Rerunning
  the same seeds, environment and commit would stop in the same place, so such an abort is not
  relaunched: it is reported as `ABORTED_GUARD_V` or `ABORTED_TAU_RANGE`, with the progress log
  and the traceback, and it is not a PASS. These two names are labels of the result document;
  the code raises an exception and writes no verdict.
- **Entry point:** `python -m nachocausal2p1.validate` runs `validate.run()` with its defaults
  (seeds from the committed C2 manifest, `guard=True`, `write=True`) and prints the verdict and the result path. The
  validation label refuses `write=False` (O8 review, D3 and D4).
- **Provenance launch file** `results/validation_004_provenance_launch.txt`. No code writes it;
  it is produced by these commands, run in order from the repo root on the C2 commit, with
  `PY=/home/ignac/nachocausal/.venv/bin/python` and `C1=<full C1 SHA>` (comité 053 §8 item 6):

  ```bash
  export NUMBA_NUM_THREADS=20      # before the block, so that `env` below records it
  F=results/validation_004_provenance_launch.txt; mkdir -p results
  { echo "start_utc $(date -u +%FT%TZ)"
    echo "head $(git rev-parse HEAD) branch $(git rev-parse --abbrev-ref HEAD) c1 $C1"
  ```

"""C2 seed-manifest producer and reader (CANDIDATE; no draw before explicit C2).

C1 seals the instrument and recipe. C2 adds only docs/validation_004_seeds.json.
This module draws seed identifiers, never causets, and is their permanent generator.
Future authorised C2: python -m nachocausal2p1.seed_manifest <full-C1-SHA>
The SHA rule supplies reproducibility, not externally supplied randomness.
"""

from __future__ import annotations

import argparse
import json
import os
from pathlib import Path
import subprocess

import numpy as np

from . import thresholds

ROOT = Path(__file__).resolve().parents[1]
MANIFEST_REL = "docs/validation_004_seeds.json"
MANIFEST_PATH = ROOT / MANIFEST_REL
FROZEN_DOC = "docs/preregistration_004.md"
SEALED_PATHS = ("nachocausal/", "nachocausal2p1/", FROZEN_DOC)


def _git(*args: str) -> str:
    result = subprocess.run(["git", "-C", str(ROOT), *args], capture_output=True, text=True)
    if result.returncode:
        raise RuntimeError(f"C2 provenance check failed: git {' '.join(args)}: {result.stderr}")
    return result.stdout


def _check_freeze(freeze_commit: str) -> None:
    if thresholds.STATUS != "FROZEN":
        raise RuntimeError("C2 manifest requires the C1 FROZEN instrument.")
    thresholds.draw_seed_from_commit(freeze_commit)  # full lowercase SHA, never an abbreviation
    # C1 is the unique commit introducing the frozen document, not a later convenient SHA.
    # --full-history: without it, history simplification follows one parent of a merge whose
    # tree equals it, so a second C1 merged in with `-s ours` would hide the first one
    # (revisiones/2026-10-15-prereg004-c053-gemini, G8).
    introduced = _git("log", "--full-history", "--diff-filter=A", "--format=%H", "--",
                      FROZEN_DOC).splitlines()
    if introduced != [freeze_commit]:
        raise RuntimeError("freeze_commit must be the unique C1 commit introducing the frozen doc.")
    _git("diff", "--exit-code", freeze_commit, "--", *SEALED_PATHS)


def _draw(freeze_commit: str) -> list[int]:
    draw_seed = thresholds.draw_seed_from_commit(freeze_commit)
    lo, hi = thresholds.VIRGIN_BAND
    return sorted(int(s) for s in np.random.default_rng(draw_seed).choice(
        np.arange(lo, hi + 1), size=thresholds.ENSEMBLE, replace=False))


def check_manifest(doc: dict) -> dict:
    """Check binding to C1, unchanged instrument, band, and exact frozen draw recipe."""
    if not isinstance(doc, dict) or set(doc) != {"freeze_commit", "draw_seed", "seeds"}:
        raise ValueError("C2 manifest must contain exactly freeze_commit, draw_seed, seeds.")
    sha = doc["freeze_commit"]
    if not isinstance(sha, str):
        raise ValueError("freeze_commit must be a full lowercase SHA string.")
    _check_freeze(sha)
    if type(doc["draw_seed"]) is not int or doc["draw_seed"] != thresholds.draw_seed_from_commit(sha):
        raise ValueError("C2 draw_seed does not match freeze_commit.")
    seeds = doc["seeds"]
    if not isinstance(seeds, list) or any(type(s) is not int for s in seeds):
        raise ValueError("C2 seeds must be a list of integer identifiers.")
    if not seeds:
        raise ValueError("C2 manifest cannot have an empty seed list.")
    thresholds.check_validation_seeds(seeds)
    if seeds != _draw(sha):
        raise ValueError("C2 seeds do not match the sorted frozen draw recipe.")
    return doc


def load_manifest() -> dict:
    """C3 reads exactly the C2 manifest committed in HEAD, never an uncommitted substitution."""
    thresholds.assert_environment()
    raw = MANIFEST_PATH.read_text()
    if raw != _git("show", f"HEAD:{MANIFEST_REL}"):
        raise RuntimeError("C2 manifest differs from its committed HEAD version.")
    if _git("status", "--porcelain"):
        raise RuntimeError("C3 requires a clean tree before reading the C2 manifest.")
    return check_manifest(json.loads(raw))


def create_manifest(freeze_commit: str) -> Path:
    """Explicit C2 only. Refuse pre-freeze, dirty tree, instrument drift and overwriting."""
    thresholds.assert_environment()
    _check_freeze(freeze_commit)
    if MANIFEST_PATH.exists():
        raise FileExistsError("C2 manifest already exists; do not redraw or overwrite it.")
    if _git("status", "--porcelain"):
        raise RuntimeError("C2 requires a clean tree before drawing.")
    doc = {"freeze_commit": freeze_commit,
           "draw_seed": thresholds.draw_seed_from_commit(freeze_commit),
           "seeds": _draw(freeze_commit)}
    thresholds.check_validation_seeds(doc["seeds"])
    with MANIFEST_PATH.open("x") as f:
        f.write(json.dumps(doc, indent=2) + "\n")
        f.flush()
        os.fsync(f.fileno())
    return MANIFEST_PATH


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("freeze_commit", help="full SHA of the authorised C1 freeze commit")
    args = parser.parse_args()
    print(create_manifest(args.freeze_commit))

"""validate — the BLIND 2+1 runner and its PASS/FAIL verdict (CANDIDATE, not frozen).

Port of nachocausal/validate.py to the 2+1 equatorial bench (comité 052 §9 step 3). Order of
operations per seed: GENERATE (validity checks) -> per kind: Guard-v -> ESTIMATE (order only)
-> GATE; the blind threshold is frozen from O; ONLY THEN is r revealed to the isolated scoring
subpackage. The estimator never receives r (split record: blind dict, then score dict).

  * thresholds keyed by rho at the frozen T, never by realised N;

# =============================================================================
# Frozen statistical primitives (as 1+1, with the 2+1 constants).
# =============================================================================
def signflip_perm_p(d) -> float:
    """One-sided exact paired sign-flip p-value for mean(d) > 0 (as nachocausal.validate)."""
    d = np.asarray(d, float)
    d = d[np.isfinite(d)]
    n = d.size
    if n == 0:
        return float("nan")
    obs = d.mean()
    if n <= thresholds.PERM_EXACT_MAX_N:
        idx = np.arange(1 << n)
        bits = (idx[:, None] >> np.arange(n)[None, :]) & 1
        means = ((1 - 2 * bits) * d[None, :]).mean(axis=1)
    else:
        rng = np.random.default_rng(0)
        signs = 1 - 2 * rng.integers(0, 2, size=(thresholds.PERM_RANDOM_SAMPLES, n))
        means = (signs * d[None, :]).mean(axis=1)
    return float(np.mean(means >= obs - 1e-12))


def _iqr(x) -> float:
    x = np.asarray(x, float)
    x = x[np.isfinite(x)]
    if x.size < 2:
        return float("nan")
    q75, q25 = np.percentile(x, [75, 25])
    return float(q75 - q25)


# =============================================================================
# Generation with validity checks (an invalid seed is counted, never replaced).
# =============================================================================
def check_seed(seed: int) -> None:
    """Runnable seed guard (comité 052:353; auditor report 043, finding 2). RAISES unless the seed
    is in the 2+1 exploration band, or is in the committed C2 manifest after the freeze.
    Virgin-band seeds can therefore never be generated before C1/C2, and burned Phase-A seeds
    (outside the band) never at all."""
    s = int(seed)
    if s in thresholds.BURNED_PHASE_A_SEEDS:
        raise RuntimeError(f"seed {s} is a burned Phase-A seed.")
    if thresholds.EXPLORE_BAND[0] <= s <= thresholds.EXPLORE_BAND[1]:
        return
    if thresholds.STATUS == "FROZEN" and s in thresholds.validation_seeds():
        return
    raise RuntimeError(f"seed {s} is outside the exploration band and not a frozen validation "
                       f"seed; virgin seeds {thresholds.VIRGIN_BAND} are reserved for C3.")


def generate(seed: int, rho: float) -> dict:
    check_seed(seed)
    rng = np.random.default_rng(seed)
    t, r, phi = generator.sprinkle(thresholds.n_mean(rho), rng)
    reasons: List[str] = []
    stats: dict = {}
    try:
        bh, stats = generator.bh_order(t, r, phi, rng=rng, audit=thresholds.AUDIT_PAIRS)
    except AssertionError as exc:            # fine shooting missed
        return {"t": t, "r": r, "phi": phi, "bh": None, "mk": None, "stats": {},
                "invalid": True, "reasons": [f"generator_assertion: {exc}"]}
    mk = generator.mink_order(t, r, phi)
    for part, a in stats.get("audit_vs_fine", {}).items():
        if a["endpoint_failures"] or a["disagreements_among_hit"]:
            reasons.append(f"audit_{part}: {a}")
    tv_bh = generator.transitivity_violations(bh)
    tv_mk = generator.transitivity_violations(mk)
    mism, _ = generator.radial_check(t, r)
    stats.update(transitivity_violations_BH=tv_bh, transitivity_violations_MINK=tv_mk,
                 radial_check_mismatches=mism)
    if tv_bh:
        reasons.append(f"transitivity_BH={tv_bh}")
    if tv_mk:
        reasons.append(f"transitivity_MINK={tv_mk}")
    if mism:
        reasons.append(f"radial_check_mismatches={mism}")
    return {"t": t, "r": r, "phi": phi, "bh": bh, "mk": mk, "stats": stats,
            "invalid": bool(reasons), "reasons": reasons}


# =============================================================================
# Per-seed blind phase (order only) -> then reveal r to score.
# =============================================================================
def per_seed(seed: int, rho: float, guard: bool = True) -> dict:
    t0 = time.time()
    g = generate(seed, rho)
    row: Dict[str, object] = {"seed": int(seed), "rho": float(rho), "N": int(g["t"].size),
                              "invalid": g["invalid"], "invalid_reasons": g["reasons"],
                              "generator_stats": g["stats"]}
    if g["invalid"]:
        row["seconds"] = round(time.time() - t0, 1)
        return row
    blind = {kind: estimator.estimate(order, guard=guard, guard_seed=int(seed))
             for kind, order in (("BH", g["bh"]), ("MINK", g["mk"]))}
    # thr is frozen from O alone for both kinds; ONLY NOW is r revealed (BH only).
    bh, mk = blind["BH"], blind["MINK"]
    if bh["abstained"]:
        br = dict(valid=False, r_lo=float("nan"), r_hi=float("nan"), width=float("nan"),
                  midpoint=float("nan"), covers=False, clean=False)
    else:
        br = blind_bracket(bh["O_by_min"], bh["min_idx"], bh["thr"], g["r"])
    row.update(sep_BH=bh["sep"], sep_MINK=mk["sep"], d=bh["sep"] - mk["sep"],
               abstained_BH=bh["abstained"], abstained_MINK=mk["abstained"],
               n_minimal_BH=bh["n_minimal"], n_minimal_MINK=mk["n_minimal"],
               improvement_BH=bh["improvement"], improvement_MINK=mk["improvement"], **br)
    row["seconds"] = round(time.time() - t0, 1)
    return row


def summarise_level(rows: List[dict], rho: float) -> dict:
    """Level statistics from per-seed rows (pure function: used by run_level and by the
    step-4 can-fail test on synthetic rows)."""
    ok = [r for r in rows if not r["invalid"]]
    res = {
        "rho": float(rho),
        "n_mean": thresholds.n_mean(rho),
        "n_seeds": len(rows),
        "n_invalid": len(rows) - len(ok),
        "n_generator_valid": len(ok),
        "n_abstain_BH": int(sum(bool(r["abstained_BH"]) for r in ok)),
        "n_escape_MINK": int(sum(not r["abstained_MINK"] for r in ok)),
        "theta_loc": thresholds.theta_loc(rho),
        "theta_stab": thresholds.theta_stab(rho),
        "slack_over_2M": thresholds.convergence_slack(rho),
    }
    res["p_perm"] = signflip_perm_p([r["d"] for r in ok])
    res["significant"] = bool(res["p_perm"] <= thresholds.P_PERM_THRESHOLD
                              and res["n_abstain_BH"] < thresholds.BH_ABSTAIN_FAIL)
    brk = [r for r in ok if r["valid"]]
    clean = [r for r in brk if r["clean"]]
    widths = np.array([r["width"] / thresholds.TWO_M for r in clean])
    res["n_bracket_valid"] = len(brk)
    res["n_clean"] = len(clean)
    res["median_width_over_2M"] = float(np.median(widths)) if widths.size else float("nan")
    res["iqr_width_over_2M"] = _iqr(widths)
    res["loc_pass"] = bool(res["median_width_over_2M"] <= res["theta_loc"])
    res["loc_inconclusive"] = not bool(res["iqr_width_over_2M"] <= res["theta_loc"])
    res["coverage_count"] = int(sum(bool(r["covers"]) for r in brk))
    res["coverage_frac"] = res["coverage_count"] / len(brk) if brk else float("nan")
    mids = np.array([r["midpoint"] for r in clean])
    res["boundary_r_std"] = float(np.std(mids)) if mids.size else float("nan")
    res["stab_pass"] = bool(res["boundary_r_std"] <= res["theta_stab"])
    res["escape_pass"] = bool(res["n_escape_MINK"] <= thresholds.MAX_MINK_ESCAPES)
    # Report descriptive aggregates even when too few generator-valid seeds make the level
    # INCONCLUSIVE. Empty samples retain NaN and zero counts; they cannot produce a PASS.
    res["status"] = "scored" if len(ok) >= thresholds.MIN_VALID_SEEDS else "inconclusive"
    return res


def progress_line(row: dict) -> dict:
    """The blind subset of a per-seed row that goes to the progress log (pure)."""
    return {k: row.get(k) for k in PROGRESS_FIELDS}


def append_progress(path: str, obj: dict) -> None:
    """Append one JSON line to the progress log and fsync it, so it survives a crash."""
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "a") as f:
        f.write(json.dumps(obj, default=_json_default) + "\n")
        f.flush()
        os.fsync(f.fileno())


def run_level(seeds, rho: float, guard: bool = True, progress: Optional[str] = None) -> dict:
    rows = []
    for s in seeds:
        row = per_seed(s, rho, guard)
        rows.append(row)
        if progress is not None:
            append_progress(progress, progress_line(row))
    res = summarise_level(rows, rho)
    res["rows"] = rows
    return res


def verdict_from_levels(levels: Dict[float, dict], *, guard_ran: bool) -> dict:
    """Frozen-form verdict from level summaries (pure; exercised by the can-fail test)."""
    prim = levels[thresholds.PRIMARY_RHO]
    short = [rho for rho in thresholds.RHO_GRID if levels[rho].get("status") != "scored"]
    if short:
        return {"verdict": "INCONCLUSIVE",
                "reason": f"rho={short} have fewer than {thresholds.MIN_VALID_SEEDS} "
                          f"generator-valid seeds"}
    required = [rho for rho in thresholds.RHO_GRID if rho >= thresholds.SIGNIFICANCE_MIN_RHO]
    sig_ok = all(levels[rho].get("significant", False) for rho in required)
    slack_ok = True
    grid = list(thresholds.RHO_GRID)
    for a_rho, b_rho in zip(grid[:-1], grid[1:]):
        a, b = levels[a_rho], levels[b_rho]
        if a.get("status") != "scored" or b.get("status") != "scored":
            slack_ok = False
            break
        if not (b["median_width_over_2M"] <= a["median_width_over_2M"] + a["slack_over_2M"]):
            slack_ok = False
    checks = {
        "i_significant_every_rho_ge_min": bool(sig_ok and prim["significant"]),
        "ii_localisation_primary": bool(prim["loc_pass"] and not prim["loc_inconclusive"]
                                        and prim["coverage_frac"] >= thresholds.COVERAGE_FLOOR),
        "ii_convergence_slack": bool(slack_ok),
        "iii_stability_primary": bool(prim["stab_pass"]),
        "iv_flat_escapes_primary": bool(prim["escape_pass"]),
        # (v) Guard-v ran on every causet (it RAISES on failure, aborting the run); a run with
        # the guard off can never pass (v) (auditor report 043, finding 1).
        "v_order_only": bool(guard_ran),
    }
    return {"verdict": "PASS" if all(checks.values()) else "FAIL", "checks": checks}


# =============================================================================
# Full run -> verdict.
# =============================================================================
def run(seeds=None, label: str = VALIDATION_LABEL, guard: bool = True, write: bool = True,
        t_edge: Optional[float] = None) -> dict:
    thresholds.assert_environment()
    validation_seeds = thresholds.validation_seeds()
    seeds = list(validation_seeds if seeds is None else seeds)
    if not seeds:
        raise RuntimeError("no seeds: the C2 manifest has not been drawn and committed.")
    for s in seeds:
        check_seed(s)
    if label != VALIDATION_LABEL and set(seeds) & set(validation_seeds):
        raise RuntimeError("validation seeds may only be run under the validation label.")
    if label == VALIDATION_LABEL:
        if not write:
            raise RuntimeError("the validation run must write its result (write=True).")
        if not guard:
            raise RuntimeError("the validation run requires Guard-v (guard=True).")
        if thresholds.STATUS != "FROZEN" or tuple(seeds) != tuple(validation_seeds):
            raise RuntimeError("the validation label is reserved for the single blind run on the "
                               "committed C2 manifest seeds after C1/C2.")
        if os.path.exists(_result_path(label)):
            raise RuntimeError(f"{_result_path(label)} exists: the blind run is one-shot.")
        thresholds.assert_blind_threads()
    t_edge = thresholds.T_EDGE if t_edge is None else float(t_edge)
    if t_edge < thresholds.T_EDGE_MIN:
        out = {"label": label, "seeds": seeds, "t_edge": t_edge, "verdict": "OUT_OF_DOMAIN",
               "reason": f"t_edge={t_edge} < T_EDGE_MIN={thresholds.T_EDGE_MIN} (not a FAIL)"}
        if write:
            write_atomic(out, label)
        return out
    if t_edge != generator.T_EDGE:
        raise RuntimeError("t_edge must equal the generator's literal T_EDGE (no T knob).")
    progress = _progress_path(label) if write else None
    if progress is not None:
        append_progress(progress, {"event": "start", "label": label, "seeds": seeds,
                                   "time": time.strftime("%Y-%m-%dT%H:%M:%S%z")})
    levels = {rho: run_level(seeds, rho, guard, progress) for rho in thresholds.RHO_GRID}
    out = {"label": label, "status_of_thresholds": thresholds.STATUS, "seeds": seeds,

def write_atomic(obj: dict, label: str) -> str:
    """Write results/<label>.json atomically: temp file in the same dir, fsync, rename."""
    os.makedirs(RESULTS_DIR, exist_ok=True)
    path = _result_path(label)
    fd, tmp = tempfile.mkstemp(prefix=f".{label}.", suffix=".tmp", dir=RESULTS_DIR)
    try:
        with os.fdopen(fd, "w") as f:
            json.dump(obj, f, indent=2, default=_json_default)
            f.flush()
            os.fsync(f.fileno())
        os.replace(tmp, path)
    except BaseException:
        if os.path.exists(tmp):
            os.unlink(tmp)
        raise
    return path

        row = {"seed": rec["seed"], "invalid": False, "abstained_BH": bh["abstain"],
               "abstained_MINK": mk["abstain"], "d": sep_bh - sep_mk, "valid": bh["claimed"]}
        if bh["claimed"]:
            w = bh["width_over_2M"] * thresholds.TWO_M
            row.update(width=w, clean=bool(w >= 0.0), midpoint=bh["mid"],
                       covers=bh["covers_2M"])
        rows.append(row)
    return rows


def _synthetic_rows(rho, escapes=0, n=thresholds.ENSEMBLE):
    """An all-good level: every seed claims, d > 0, bracket of width theta_loc/2 centred on 2M,
    flat control abstains except on the first `escapes` seeds."""
    w = 0.5 * thresholds.theta_loc(rho) * thresholds.TWO_M
    return [{"seed": i, "invalid": False, "abstained_BH": False, "abstained_MINK": i >= escapes,
             "d": 1.0 + 0.01 * i, "valid": True, "clean": True, "width": w,
             "midpoint": thresholds.TWO_M, "covers": True} for i in range(n)]


@functools.lru_cache(maxsize=None)
def _synthetic_level(rho, escapes=0):
    return validate.summarise_level(_synthetic_rows(rho, escapes), rho)


def _levels(primary):
    lv = {rho: dict(_synthetic_level(rho)) for rho in thresholds.RHO_GRID}
    lv[PRIM] = primary
    return lv
